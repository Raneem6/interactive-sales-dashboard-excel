# Interactive Sales Dashboard in Excel

This project is an interactive sales dashboard created using Microsoft Excel.  
The dashboard is designed to provide insights into sales performance across various dimensions, helping users analyze key metrics effectively.

---

## Project Overview

The dashboard visualizes sales data with a combination of pivot tables, slicers, charts, and map visualizations.  
It allows filtering by customer type, time period (year, quarter, month), product category, and state, enabling dynamic exploration of the data.

---

## Key Performance Indicators (KPIs)

- **Total Sales:** Total revenue generated
- **Total Units Sold:** Number of units sold
- **Total Customers:** Number of distinct customers
- **Number of Cities:** Count of cities with sales
- **Number of Products:** Total products sold

---

## Dashboard Features

- **Customer Type Breakdown:** New Customer, Loyal Customer, Retail
- **Time Filters:** Year, Quarter, Month slicers for time-based analysis
- **Product and State Filters:** Easily segment sales by product and geographic location
- **Returned Sales and Units:** Tracking of returned items and their value
- **Delayed Orders:** Monitoring orders with delivery delays
- **Interactive Map:** Sales distribution by U.S. states using Excel's map chart
